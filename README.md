# ПТИЦА.ПРО — сайт оптовых поставок куриного сырья

Готовый статический сайт (HTML/CSS/JS, без сборки и зависимостей). Открывается локально, ставится на любой хостинг простым копированием файлов.

## Запуск

```bash
python -m http.server 8123
```

Затем открыть http://localhost:8123

## Структура

```
poultry-site/
├── index.html      Главная: оффер, показатели, категории, преимущества,
│                   производство, процесс, логистика, отзывы, FAQ, CTA
├── catalog.html    Каталог: фильтры по категории и состоянию, поиск,

├── delivery.html   Доставка: 3 сценария, тарифы по направлениям,
│                   холодовая цепь, оплата и документооборот, FAQ

    │                   панель заявки с localStorage, FAQ, анимации
```

## Что уже работает

- Панель «Заявка»: добавление позиций из каталога, шаг по 0,5 тонны, расчёт ориентировочной суммы, сохранение между страницами (localStorage).
- Фильтрация каталога по категории и состоянию + живой поиск по названию, артикулу и ГОСТ.
- Глубокие ссылки в каталог: `catalog.html?cat=file` и т.д.
- Мобильное меню, аккордеон FAQ, анимация появления блоков, анимированные счётчики.
- Адаптив от 375 px до широкого десктопа.

## Что нужно заменить перед публикацией

Все данные — демонстрационные, подставлены как реалистичная заглушка:

- Название, логотип, домен `ptica.pro`, телефоны, e-mail, адреса, ИНН/ОГРН/р-с.
- Цифры: объёмы отгрузки, мощности, число клиентов, доли рекламаций, стратегия.
- Цены и минимальные партии в `assets/js/app.js` → массив `PRODUCTS`.
- Названия клиентов в блоке логотипов и отзывы на главной.
- Ссылки «Политика обработки персональных данных» и «Договор оферты» (сейчас `#`).

Реальны и проверяемы только ссылки на нормативы: ГОСТ 31962-2013 (мясо кур),
ГОСТ 31657-2012 (субпродукты птицы), ГОСТ 31490-2012 (мясо птицы механической
обвалки), ТР ТС 021/2011, ТР ТС 034/2013, ФГИС «Меркурий».

## Что нужно доделать для боевой версии

1. **Приём заявок.** Сейчас формы имитируют отправку на клиенте (`app.js`, обработчик `form[data-form]`). Нужен бэкенд или сервис форм: отправка на e-mail/в CRM/в Telegram.
2. **Фото продукции.** Иллюстрации SVG — стилизованные. Для инвестора работают, для продаж лучше добавить фотосъёмку.
3. **Карта** на странице контактов — заглушка, подключить Яндекс.Карты.
4. **Прайс XLSX** — файл для скачивания по кнопке «Запросить прайс».
5. **Аналитика** — Яндекс.Метрика, цели на отправку форм.
6. **SEO** — sitemap.xml, robots.txt, микроразметка Organization и Product.

## Версия для ссылки (share/)

`share/index.html` — тот же сайт, собранный в **одну страницу** с навигацией через
хеш (`#catalog`, `#company`, `#quality`, `#delivery`, `#contacts`). Папка `share/`
самодостаточна: в ней лежит своя копия `assets/`, её можно залить на любой
статический хостинг целиком.

Пересобрать после правок основных страниц:

```bash
node scripts/build-share.js
```

Опубликовано как артефакт Claude (приватная ссылка, открывается без сервера).

## Один файл для пересылки

`ptica-pro.html` (121 КБ) — весь сайт в одном файле: стили, скрипт и картинки
вшиты внутрь. Открывается двойным кликом, без сервера и без интернета
(без сети подхватятся системные шрифты вместо Google Fonts).
Пересобрать: `node scripts/build-single.js`
